# Revision Timetable

A shared revision timetable app for Christian, Luca, and Will.

## Features

- Exam countdowns and generated study sessions
- Editable timetable and calendar view
- Topic and progress tracking
- Shared Supabase sync for profiles and leaderboard
- Light and dark mode

## Hosting

This is a static site. It can be hosted with GitHub Pages from the repository root.
